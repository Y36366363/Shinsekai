# 四宫辉夜角色包（Shinsekai）

这是一个面向本地个人使用的 Shinsekai `.char` 角色包初版，包含完整中文人格设定和 4 张原创透明立绘。最终立绘均为带 Alpha 通道的 RGBA PNG；生成时使用的绿色抠图底图不会被打进 `.char`，也不保留在项目交付目录中。包内不包含官方动画素材、原作台词、声优录音或声音克隆模型。

## 已完成

- 四宫辉夜的人格、语言习惯、互动边界与关系成长规则
- 从容 / 害羞 / 严肃 / 温柔四类立绘及情绪标签
- 中文 TTS 参考文本、语速、音量和日语姓名读音映射
- 4 套可直接复制的开场情景
- 一键打包脚本与结构验证

## 导入

1. 在仓库根目录运行 `python character_packs/shinomiya_kaguya/build_pack.py`。
2. 启动 Shinsekai，打开「角色管理」。
3. 选择 `dist/shinomiya-kaguya-v0.1.0.char` 并导入。
4. 打开「聊天模板」，勾选“四宫辉夜”，填写一个情景并生成模板。
5. 在「API 设定」配置 LLM；暂不配置 TTS 也可以正常文字聊天。
6. 启动聊天，用 `SCENE_STARTERS.md` 末尾的四句话测试立绘切换。

## 推荐模型参数

- 温度：`0.65`—`0.8`，建议先用 `0.72`
- 流式输出：开启
- 长期记忆：先关闭完成人格测试，稳定后再开启
- 自动记忆间隔：开启后建议 `5`—`8` 轮
- TTS：可选择 `openai-standard` 使用普通合成音色；API Key 在设置页面填写

## 语音说明

角色包故意不附带声优声音或克隆模型。普通阶段使用 `plugins/openai_standard_tts`；后续音轨、固定立绘语音和授权参考音频的接入方法见 `AUDIO_ASSETS.md`。中文对话优先把 `prompt_lang` 保持为 `zh`；如果改用日语 TTS，需要同时准备日语参考文本。

## 替换立绘

当前图片是使用图像生成工具制作的原创占位资源。你可以在角色管理中删掉并上传自己的透明 PNG；上传顺序必须与 `character.yaml` 的情绪标签顺序一致：从容、害羞、严肃、温柔。
