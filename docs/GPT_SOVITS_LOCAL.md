# 独立 GPT-SoVITS 服务（试听阶段）

## 英文课堂切换

先关闭旧聊天，再双击项目中的 `English-Classroom.command`，完成后重新打开“辉夜聊天”，开始新聊天。
该模式使用英文正文、英文配音。双击 `Chinese-Chat.command` 可恢复中文正文、日语配音。
两种模式都保留角色内部名字“四宫辉夜”，避免破坏记忆、立绘与语音匹配。
英文台词（包含英文字母且不含中日文字）在聊天名牌及历史中显示为 `Shinomiya`；英文语音模式下聊天名牌也固定使用此简称。中文模式的中文台词保留原名。
这是显示别名，不改变模型返回的 character_name。

英文合成仍使用已试听的日语参考录音，参考语言保持 ja，目标语言为 en。
英文接口已实测生成两句 WAV，发音和音色需人工试听，不保证与日语同样自然。
试听文件：`temp/gpt-sovits-audition/english-1.wav`、`english-2.wav`，均为 AI 合成。

## 自动配音（2026-10-22）

已试听满意后，可运行 `.venv/bin/python scripts/enable_kaguya_speech.py` 启用。
脚本备份原配置到 `data/backups/before-auto-speech-*`，保留密钥等其他设置，
使用已试听的 time_noon2.wav 和无参考字幕模式。

1. 关闭原来的辉夜聊天窗口，重新双击“辉夜聊天”。
2. 桌面会自动启动本地语音服务；看到载入模型提示时稍等，不必另开终端。
3. 使用恢复的日常聊天模板开始新聊天，输入中文。回复中文显示，日语自动播放。
   不要从旧聊天历史继续测试，以免沿用旧的无翻译提示词。
4. 第一条可能较慢；每条需等待语音合成。请打开系统音量，不要将聊天页面静音。

桌面退出时只关闭本次自行启动的语音服务，不关闭已在外部运行的服务。
浏览器方式仍需先运行 `start-gpt-sovits.command`。
模型输出需带有日语 `translate` 字段；本地模板已补充要求，但不能保证模型永远遵循。
如自行换模板，请开启翻译、语音语言选日语。声音为 AI 合成，非官方配音。

回退：在 AI 服务选择 `kaguya-voicepack` 并重新打开聊天；录音包文件没有删除。
如需完整恢复，将上述备份中的四个配置文件放回 `data/config`，
`_temp.txt` 和 `_temp_split.json` 放回 `data/character_templates`（先关闭程序）。

服务与聊天环境分开，位于 runtime-services；源码和模型不会上传 Git。
源码版本：b4570b876f5c086819ba84e3215472733c6a7b70。
模型：官方 lj1995/GPT-SoVITS 的 v2 推理模型及 Hubert、BERT。
模型快照：8f8857563c040d542de108a2c18b0425abd6c9c5。
初始使用 CPU / float32 验证兼容性，不预先承诺实时速度或原声相似度。

首次或恢复安装：`bash scripts/install_gpt_sovits.sh`。

启动：双击 `start-gpt-sovits.command`，等待模型载入。服务只监听 127.0.0.1:9880，接口文档为 http://127.0.0.1:9880/docs 。终端 Control+C 停止服务。

准备具有适当使用许可的干净日语参考音频及逐字台词后，可用主项目环境试听：

```bash
.venv/bin/python scripts/test_gpt_sovits_local.py --reference '/完整路径/参考.wav' --transcript '录音中准确的日语台词'
```

输出在 temp/gpt-sovits-audition，包含两句新台词和生成耗时。参考音频应满足模型长度限制（通常 3–10 秒）；不要用静音填充掩盖过短样本。动画剪辑中音乐和多人对白会影响效果。下载固定播放包不代表同时获得声音合成授权。

试听满意之后才在 AI 服务切换到 gpt-sovits，地址填 http://127.0.0.1:9880/，自动启动目录留空（使用这里独立启动的服务）。角色参考音频填绝对路径、参考文本填逐字台词、参考语言选择 ja。通用 v2 推理不要求再填写微调模型路径。

日常模板保留中文正文，开启翻译并把语音语言设为 ja，再生成保存模板：项目将正文用于显示，将翻译字段用于合成。切换后需检查生成模板确实要求日语翻译；不能仅改角色参考语言。已有日常模板与录音包目前保持不变。

退回录音包：AI 服务选择 kaguya-voicepack 并重启聊天。

## 已验证状态（2026-10-21）

本机独立 Python 环境及模型已安装；CPU 服务成功载入全部模型，
`/openapi.json` 返回 HTTP 200，日语词典初始化及日语转音素检查通过。
随后已使用本地录音包 time_noon2.wav（8.32 秒）完成两句新台词合成。
因原仓库没有核对过的逐字台词，使用 v2 的无参考文本模式，没有猜写字幕。
本次 CPU 测试：第一句生成 6.78 秒、音频 5.94 秒；第二句生成 2.91 秒、音频 5.22 秒。
耗时只代表本次运行，不保证聊天中的响应速度。WAV 格式和非空时长已检查；
音色、发音、背景噪音及自然度仍需要人工试听。当前聊天继续使用录音包，没有自动切换。
